# Playbooks

Thin domain sheets carrying what the universal method cannot know. The mechanism — when one is
summoned, how one is researched and drafted, how corrections travel back, how evolution stays
legible — lives in one place: the **Domain playbooks** section of `../AGENTBRIDGE-BUILD-DIRECTIVE.md`.

One fact lives only here: **birth tags.** A playbook drafted from studying real practitioners is
`researched`; one distilled from a deployment under this method is `felt`. Rules inside carry the
same tags. Homework and scar tissue are both valuable and never confused.
